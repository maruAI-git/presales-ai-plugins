# 프리세일즈 연결

1. 이 플러그인은 한국어 제안서·RFP 대응·PPT를 작성하는 사용자의 AI에 프리세일즈 노하우와 페이지 템플릿을 제공한다. 기존 문서 마켓플레이스와 이 플러그인의 자료 이용권은 구분한다. 플러그인에서 문서·크레딧 판매나 업그레이드를 제안하지 않는다.
2. 플러그인에 포함된 `presales` MCP 연결을 사용한다. 연결 도구가 없으면 설치·활성화와 클라이언트의 연결 기능을 안내한다. 이 스킬이 실행됐다는 이유만으로 연결 성공을 선언하지 않는다.
3. OAuth 인증이 필요하면 클라이언트가 여는 프리세일즈 로그인·연결 화면으로 안내한다. 기존 회원은 로그인하고, 신규 회원은 사이트에서 필수 가입정보와 동의를 확인한 뒤 연결 권한을 승인한다. 비밀번호·개인 API 키·OAuth 코드·토큰을 채팅에 요구하거나 출력하지 않는다. 사용자 대신 약관·연령·개인정보 동의를 누르지 않는다.
4. OAuth는 `knowhow:read`, `knowhow:write`만 요청한다. S256 PKCE와 동적 클라이언트 등록은 MCP 클라이언트와 서버가 처리한다. 수동 헤더·장기 키·클라이언트 비밀키를 만들거나 설정하지 않는다.
5. 연결 후 `presales_catalog`와 `presales_projects`로 실제 목록·작성 크레딧을 확인한다. 조회만으로 크레딧을 쓰지 않는다. 도구 응답이 오류면 성공으로 표시하지 않는다.
6. 작성 프로젝트 예약은 사용자가 이미 보유한 작성 크레딧과 승인한 한도(최대 200) 안에서만 가능하며, 페이지 자료 이용권을 발급할 때 1페이지당 작성 1크레딧이 차감된다. 완성 문서의 실제 페이지 수를 사후 측정해 과금하는 방식이 아니다. 작성은 사용자의 AI가 수행한다. 잔액이 부족하면 현재 이용 권한으로 실행할 수 없음을 설명하고 이 가이드의 비거래 정보를 안내한다. 가격표·구매·충전·업그레이드 제안이나 거래를 시작하는 페이지 연결은 하지 않는다.
7. 해제 요청에는 https://presales.co.kr/proposals/connect/manage 에서 해당 연결을 해제하고 클라이언트에서도 연결을 제거하도록 안내한다. 토큰 폐기와 미사용 프로젝트 예약 해제는 별개이므로 진행 중 프로젝트가 있으면 종료 여부를 확인한다. 해제 후 도구를 호출하거나 재연결을 강요하지 않는다.
